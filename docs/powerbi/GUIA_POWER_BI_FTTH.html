Guía: Dashboard de Control del Despliegue FTTH en Power BI

Nov 10, 2026 · TEK-COM · mismo diseño de la guía de producción, con los datos del proyecto FTTH

Resumen y archivos

Todo va en una sola página de 1280 × 720 px (16:9), sin desplazamiento. La imagen de fondo dibuja la barra lateral, los paneles blancos, las tarjetas y los íconos. Encima colocas visuales con transparencia, cada uno con tamaño y posición exactos. Es la misma estructura de la guía del tablero de producción: lo único que cambia son los datos, las medidas y los gráficos.

Paso 0 — Obtener los datos del sistema

  1. Entra al sistema de proyectos, abre Presentación y toca el botón Datos para Power BI (arriba a la derecha). Se descarga DATOS_POWER_BI_FTTH.xlsx.
  2. Guárdalo en la carpeta de SharePoint u OneDrive de TEK-COM (no en Descargas). Así Power BI en la nube puede leerlo y refrescarlo solo.
  3. Para actualizar los datos: descarga el archivo de nuevo desde el sistema y reemplaza el que está en SharePoint/OneDrive (mismo nombre). Los números del sistema y los del tablero salen de la misma fuente.

Paso 1 — Datos y modelo

El modelo es una estrella: 4 tablas de hechos y 3 dimensiones que filtran a las cuatro al mismo tiempo. Así cada filtro de la barra lateral mueve todos los gráficos.

  1. Inicio › Obtener datos › Libro de Excel y elige DATOS_POWER_BI_FTTH.xlsx. Marca las 8 tablas (no marques la hoja Leeme) y dale Transformar datos. Si lo guardaste en SharePoint/OneDrive, usa Obtener datos › Web con el enlace del archivo para que se actualice solo.
  2. En Power Query revisa los tipos: las fechas como Fecha, las cantidades como Número decimal y los 0/1 como Número entero. Luego Cerrar y aplicar.
  3. Modelado › Nueva tabla y pega el calendario:
dCalendario =
VAR _ini = DATE ( YEAR ( MIN ( fInstalado[Fecha] ) ), 1, 1 )
VAR _fin = DATE ( YEAR ( MAX ( fInstalado[Fecha] ) ), 12, 31 )
RETURN
    SELECTCOLUMNS (
        CALENDAR ( _ini, _fin ),
        "Fecha", [Date],
        "Año", YEAR ( [Date] ),
        "MesNum", MONTH ( [Date] ),
        "Mes", SWITCH ( MONTH ( [Date] ), 1, "Enero", 2, "Febrero", 3, "Marzo", 4, "Abril", 5, "Mayo", 6, "Junio", 7, "Julio", 8, "Agosto", 9, "Septiembre", 10, "Octubre", 11, "Noviembre", 12, "Diciembre" ),
        "MesCorto", SWITCH ( MONTH ( [Date] ), 1, "ene", 2, "feb", 3, "mar", 4, "abr", 5, "may", 6, "jun", 7, "jul", 8, "ago", 9, "sep", 10, "oct", 11, "nov", 12, "dic" )
    )
  1. Con dCalendario seleccionada: Herramientas de tabla › Marcar como tabla de fechas y elige la columna Fecha.
  2. Ordena para que meses, estados, partidas y etapas no salgan en orden alfabético (Herramientas de columna › Ordenar por columna):
    • dCalendario[MesCorto] y dCalendario[Mes] por MesNum
    • dEstado[Estado] por Orden (Finalizado, En avance, Sin iniciar)
    • fPartidas[Partida] por OrdenPartida
    • fEtapas[Etapa] por OrdenEtapa
  3. En la vista de modelo deja exactamente estas relaciones, todas Uno a varios con dirección de filtro Única:
Desde (lado 1)Hacia (lado varios)
dCalendario[Fecha]fInstalado[Fecha]
dBrigada[Brigada]fNodos[Brigada], fInstalado[Brigada], fPartidas[Brigada] y fEtapas[Brigada]
dSupervisor[Supervisor]fNodos[Supervisor], fInstalado[Supervisor], fPartidas[Supervisor] y fEtapas[Supervisor]
dEstado[Estado]fNodos[Estado], fInstalado[Estado], fPartidas[Estado] y fEtapas[Estado]

Si Power BI creó solo alguna relación entre tablas de hechos (por ejemplo fNodos con fPartidas por Nodo), elimínala: las tablas de hechos solo se conectan por las dimensiones. Son 13 relaciones en total. Nota: los filtros Año y Mes mueven solo los gráficos de producción (los que salen de fInstalado); el resto es el estado actual de los nodos.

Paso 2 — Medidas DAX

Los nombres de los KPI son exactamente los textos que muestran las tarjetas: escríbelos igual, con tildes.

  1. Inicio › Especificar datos, nombre _Medidas, Cargar.
  2. Para cada medida: selecciona _Medidas, Modelado › Nueva medida, pega el código y pon el formato en Herramientas de medida.
  3. Al terminar, borra la columna “Columna1” de _Medidas.

Medidas base

Nodos = COUNTROWS ( fNodos )
Nodos Finalizados = CALCULATE ( COUNTROWS ( fNodos ), fNodos[EstadoOrden] = 1 )
FATs Proyectadas = SUM ( fNodos[FATsProyectadas] )
HP Finalizados = CALCULATE ( SUM ( fNodos[HP] ), fNodos[EstadoOrden] = 1 )
Metros Período = SUM ( fInstalado[Metros] )
FATs Período = SUM ( fInstalado[FATs] )
Piezas Período = SUM ( fInstalado[Piezas] )

KPI y apoyo

Avance físico = DIVIDE ( AVERAGE ( fNodos[AvancePct] ), 100 )
Fibra tendida (m) = SUM ( fNodos[CableMetros] )
FATs instaladas = SUM ( fNodos[FATsInstaladas] )
Piezas instaladas = SUM ( fNodos[Piezas] )
Home passes (HP) = SUM ( fNodos[HP] )
X-box fusionada = SUM ( fNodos[XBoxFusionada] )

FATs por instalar = MAX ( 0, [FATs Proyectadas] - [FATs instaladas] )
% FATs = DIVIDE ( [FATs instaladas], [FATs Proyectadas] )
HP por habilitar = [Home passes (HP)] - [HP Finalizados]
Listos para medir = SUM ( fNodos[ListoParaMedir] )
% Avance partida = DIVIDE ( SUM ( fPartidas[Instalado] ), SUM ( fPartidas[Proyectado] ) )
% Etapa finalizada = DIVIDE ( SUM ( fEtapas[Finalizada] ), COUNTROWS ( fEtapas ) )
FATs acumuladas =
VAR _f = MAX ( dCalendario[Fecha] )
RETURN CALCULATE ( [FATs Período], FILTER ( ALLSELECTED ( dCalendario ), dCalendario[Fecha] <= _f ) )
Avance acumulado de FATs = DIVIDE ( [FATs acumuladas], [FATs Proyectadas] )
Fecha Actualización = "Actualizado al " & FORMAT ( MAX ( tInfo[Corte] ), "dd/mm/yyyy" )

Textos de la franja de insights

Devuelven texto, no llevan formato.

Ins Nodo Valor =
VAR _t = FILTER ( fNodos, fNodos[EstadoOrden] = 2 )
RETURN IF ( COUNTROWS ( _t ) = 0, "—", MAXX ( TOPN ( 1, _t, fNodos[AvancePct], DESC ), fNodos[Nodo] ) )
Ins Nodo Sub =
VAR _t = FILTER ( fNodos, fNodos[EstadoOrden] = 2 )
VAR _n = TOPN ( 1, _t, fNodos[AvancePct], DESC )
RETURN IF ( COUNTROWS ( _t ) = 0, "Todos finalizados o sin iniciar",
    FORMAT ( MAXX ( _n, fNodos[AvancePct] ), "0.0" ) & "% · " & MAXX ( _n, fNodos[Brigada] ) )
Ins Nodo Ind = "● En obra"

Ins Brigada Valor =
VAR _t = FILTER ( ADDCOLUMNS ( VALUES ( dBrigada[Brigada] ), "@a", [Avance físico] ), NOT ISBLANK ( [@a] ) )
RETURN IF ( COUNTROWS ( _t ) = 0, "—", MAXX ( TOPN ( 1, _t, [@a], DESC ), dBrigada[Brigada] ) )
Ins Brigada Sub =
VAR _t = FILTER ( ADDCOLUMNS ( VALUES ( dBrigada[Brigada] ), "@a", [Avance físico] ), NOT ISBLANK ( [@a] ) )
RETURN IF ( COUNTROWS ( _t ) = 0, "Sin datos", FORMAT ( MAXX ( _t, [@a] ), "0.0%" ) & " de avance promedio" )
Ins Brigada Ind = "▲ Brigada líder"

Ins FATs Valor = FORMAT ( [FATs por instalar], "#,0" )
Ins FATs Sub = "de " & FORMAT ( [FATs Proyectadas], "#,0" ) & " proyectadas"
Ins FATs Ind = IF ( [% FATs] >= 0.9, "✔ ", "● " ) & FORMAT ( [% FATs], "0.0%" ) & " completado"

Ins Medir Valor = FORMAT ( [Listos para medir], "#,0" )
Ins Medir Sub =
VAR _l = CONCATENATEX ( FILTER ( fNodos, fNodos[ListoParaMedir] = 1 ), fNodos[Nodo], ", ", fNodos[Nodo] )
RETURN IF ( _l = "", "Ninguno todavía", _l )
Ins Medir Ind = IF ( [Listos para medir] > 0, "✔ Listos para medir potencia", "● Aún sin FATs suficientes" )

Ins HP Valor = FORMAT ( [HP por habilitar], "#,0" )
Ins HP Sub = "de " & FORMAT ( [Home passes (HP)], "#,0" ) & " HP"
Ins HP Ind = "● " & FORMAT ( DIVIDE ( [HP Finalizados], [Home passes (HP)] ), "0.0%" ) & " ya habilitado"

Publicar y actualizar

  1. Inicio › Publicar, elige el área de trabajo Desarrollo inicial y acepta Reemplazar: mantiene el mismo enlace y los mismos permisos.
  2. Para que se actualice solo en la nube, el Excel debe estar en el SharePoint/OneDrive de TEK-COM y Power BI debe leerlo desde ahí (no desde tu PC). Ya en la nube, programa el refresco en Configuración del modelo semántico › Actualización programada.
  3. Cada día (o cuando quieras) descarga Datos para Power BI desde el sistema y reemplaza el archivo de SharePoint/OneDrive con el mismo nombre; el siguiente refresco trae los números nuevos.
  4. Si el reporte ya está armado y todo quedó “para abajo”: cambia el lienzo a Tipo: 16:9, pon el fondo y mueve cada visual a las posiciones de estas tablas. No hace falta rehacerlos.
