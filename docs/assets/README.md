# Recursos gráficos

El logo que usa la aplicación está en `src/Tekcom.Gestion.Web/wwwroot/branding/`:

- `logo.png`: versión a color, para los exportes de Excel y PDF.
- `logo-blanco.png`: versión con texto blanco, para el menú lateral.

**Son logos provisionales** (iniciales TEK-COM con un símbolo de señal) hechos mientras no hay un archivo oficial.
Para usar el logo oficial de TEK-COM, reemplace esos dos archivos conservando el nombre (PNG con fondo transparente,
de unos 1200 px de ancho). No hay que tocar código.
